Childlock Support

Help for parents and guardians using Childlock.

Getting Started

  1. Install Childlock on the child's iPhone or iPad.
  2. Complete onboarding as the parent or guardian.
  3. Allow Screen Time access when prompted.
  4. Select the apps or categories that should trigger brain breaks.
  5. Set a parent PIN so the child cannot enter the parent dashboard.

Brain Breaks Are Not Appearing

  • Confirm Screen Time access is still allowed in iOS Settings.
  • Open Childlock and confirm the correct child profile is active.
  • Reselect monitored apps or categories if the device's Screen Time permissions were reset.
  • Confirm notifications are allowed for Childlock so the child sees brain break prompts.

Need More Help?

Send us the device model, iOS version, and what happened right before the issue. Please do not include a child's full name or sensitive personal information in the first message.
